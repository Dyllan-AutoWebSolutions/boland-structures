# Image swap list — Boland Structures

Every photo on the site is a placeholder from Unsplash. To replace one with your own AI image:

1. Generate the image using the prompt below.
2. Export it as a JPG at the size listed (or larger, at the same aspect ratio).
3. Save it in `assets/img/` with the **exact same filename**, replacing the old file.

You don't need to change any code.

**Style suffix (add to every prompt):**
`photorealistic, shot on a full-frame camera, warm golden-hour light, Western Cape South Africa, Boland mountains in the background where visible, colour palette of deep navy and rust orange, natural film grain, no text, no logos, no watermarks`
